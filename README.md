# Crowns Barbershop

A responsive website mockup for Crowns Hair Salon & BarberShop.

## Open the mockup

Open `outputs/crowns-barbershop-mockup.html` in a browser.

## Included

- Responsive dark navy-and-gold landing page
- Call-now and WhatsApp booking flow
- Locations, services, barber roster, and gallery sections
- Project context notes and local visual assets
